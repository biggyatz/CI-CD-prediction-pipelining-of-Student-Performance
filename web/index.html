About the model

A linear regression trained on 800 students and tested on 200 it had never seen, the split used by the project's ML pipeline. Each category is measured against a baseline category, so every coefficient reads directly as points.

Data: the "Students Performance in Exams" dataset (1,000 students) used throughout this project. The model runs entirely in your browser.
